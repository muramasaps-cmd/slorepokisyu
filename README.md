# 🎰 スロット店舗 粗利・売上分析システム (Slorepo Profit Analyzer)

スロレポの店舗出玉ページ（HTMLデータ）を取り込み、ホールの粗利推移・客収支・出玉率（機械割）・特日/曜日/末尾別傾向、および当日の狙い台予測・バックテスト精度検証を行えるWebアプリケーションです。

React 19 + TypeScript + Tailwind CSS + Recharts で構築された完全クライアントサイドSPAであり、外部サーバーやAPIキー不要で安全にブラウザ内で完結して動作します。

---

## 🌟 6大タブ構成

1. **概要**
   - 主要KPIカード（期間累計粗利、月平均粗利、最高黒字月、最大還元月）
   - 月別粗利＆累計推移グラフ（単月バー、累計折れ線、稼働G数推移）
   - 1行視点インジケーター（ホール経営目線 ⇔ スロッター収支目線のワンクリック切り替え）
   - 店舗別 換金ギャップ動的算出（貸出・交換レートと現金投資比率の連動）

2. **狙い日予測**
   - 攻略対象日（特定日・新台入替日等）の機種別・末尾別おすすめランキング
   - 過去の類似営業日（同種特日・同曜日・同末尾日）の過去実績相対評価・期待差枚・勝率の多角集計
   - 朝イチ本命・対抗・末尾立ち回り戦術サマリー

3. **機種分析**
   - 機種別の深掘り分析（設置台数、総差枚、勝率、平均G数）
   - 高出玉分析（万枚・5,000枚オーバー発生率、高設定投入挙動）
   - スマスロ・Aタイプ・ジャグラー・カスタム絞り込み

4. **日付傾向**
   - 〇のつく日別（末尾0〜9 & ゾロ目）の利益・出玉傾向分析
   - 曜日・祝日別傾向分析（平均差枚・勝率・還元傾向）
   - 旧イベント日・特日サイクル分析（特日と通常日の対比、月内特日間の相関）

5. **月別・ヒートマップ**
   - 月別詳細データ表（各月の営業日数、稼働G数、出玉率、換金ギャップ粗利、CSV出力対応）
   - 総合出玉・粗利ヒートマップ（日別カレンダーマトリクス、出玉状況の視覚的把握）

6. **精度検証（新規）**
   - **ウォークフォワード・バックテスト基盤**: 各営業日を「その日より前のデータだけ」で予測し、当日の実績と比較（ルックアヘッド・バイアス完全排除）
   - **多角的な評価指標**: 順位相関係数（スピアマン）、上位K機種の平均差枚リフト、勝率（プラス日比率）、期待差枚MAE、ホール全体予測MAE、推奨末尾成績
   - **単純ルールベンチマークとの常時対比**: 「全期間の平均差枚が高い順」と当システム複合スコアの差分（エッジ）を可視化
   - **時系列スプリット自動調整**: 学習期間70%・検証期間30%に分け、学習側でのみ重みを探索。未知の検証期間でも改善し、かつ偶然と区別できる場合（t値 ≧ 2.0）のみ採用を推奨
   - **店舗別設定保存**: 採用した最適化重みは店舗ごとに保存され、狙い日予測に即座に反映

## 🚀 セットアップ・実行方法

### 必要な環境
- Node.js (v18.0.0 以上推奨)
- npm

### 1. 依存パッケージのインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```
起動後、ブラウザで `http://localhost:3000` を開きます。

### 3. プロダクションビルド
```bash
npm run build
```
`dist/` フォルダに静的ファイルが出力されます。
